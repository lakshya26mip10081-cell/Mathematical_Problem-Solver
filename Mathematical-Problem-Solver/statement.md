# Project Statement

## 1. Project Title
**Mathematical Problem Solver**

## 2. Introduction
Mathematical calculations are essential across programming, academic coursework, and daily problem-solving. The **Mathematical Problem Solver** is a Python CLI application built to provide core numerical algorithms through a single interactive interface. The project utilizes a modular directory architecture (`src/`), keeping each operation logic isolated and maintain.

## 3. Problem Overview & Objective
- **Problem:** Performing repetitive number theory calculations (such as GCD, base conversion, and prime factor analysis) manually is time-consuming and prone to human errors.
- **Objective:** Create a lightweight, robust, and interactive Python script that automates these mathematical routines with clear input validation.

## 4. Key Features & Scope
The current version supports six foundational operations:
- **Base Conversion:** Converts values across decimal, binary, and hexadecimal bases.
- **GCD Calculation:** Computes the Greatest Common Divisor of two integers.
- **Prime Factorization:** Decomposes integers into prime components.
- **Smallest Divisor:** Identifies the lowest non-trivial factor greater than 1.
- **Square Root:** Evaluates non-negative square roots cleanly.
- **Random Number Generation:** Produces bounded random integers.

## 5. Implementation Highlights
- Interactive menu loop with input validation using `try-except` blocks.
- Modular code structure inside the `src/` directory.
- Continuous console execution until explicitly terminated by the user.
- Automated unit testing via Python's built-in `unittest` library.
