# What is mathematical-problem-solver?
Mathematical-problem-solver is the python project which help to solve the probelms related to the maths.
# Features of Mathematical-Problem_Solver
1. It helps to find the Base Conversion.
2. It helps to find the GCD.
3. It helps to find Prime factorisation.
4. It helps to find the random number.
5. It helps to find the smallest dividsor.
6. It helps to find the square root of any number.
# Projects Files are:
'src/': Directory containing all the core Python modules.
'main.py': Entry script to run the application.
'test_solver.py': Contains test methods to check if all modules work properly.
# How to Execute
To run the main.py, then code will be run on terminal then enter any number from 1 to 6.
You select which mathematical problem you want to solve using the numbers 1 through 6.
